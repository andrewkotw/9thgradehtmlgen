# 國中生網站內容填寫器

這是一個給國中生使用的單頁 HTML 產生器。學生只要在表單中填入文字、圖片 URL 和主題顏色，右側就會即時產生完整網頁預覽與 HTML 原始碼。完成後可以直接複製 HTML，或下載成 `example.html`。

這份工具的目標是讓學生在不需要任何開發環境的情況下，仍然可以理解「表單內容如何變成一份真正的 HTML 網頁」。

## 使用方式

### 直接使用線上版

開啟這個連結即可使用：

<https://andrewkotw.github.io/9thgradehtmlgen/>

學生可以直接在網頁中填寫內容、查看預覽，最後複製 HTML 或下載 `example.html`。

### 下載後自行修改

1. 下載或 clone 這個 repository。
2. 用瀏覽器開啟 `index.html`。
3. 在左側表單填入網站內容。
4. 在右側查看即時預覽。
5. 完成後按「複製 HTML」或「下載 example.html」。

不需要安裝套件，也不需要啟動伺服器。

## 主要功能

- 內容表單：填寫頁面標題、自我介紹、個人標籤、科技技能、作品故事、成長目標和未來訊息。
- 即時預覽：右側 iframe 會即時顯示學生正在建立的網站。
- HTML 原始碼檢視：可切換到「看 HTML」，並以類似程式碼編輯器的方式顯示行號和語法顏色。
- 複製與下載：可以直接複製完整 HTML，或下載成 `example.html`。
- 圖片 URL 測試：輸入圖片連結後會提示圖片是否可以載入。
- 主題顏色：提供紅、藍、綠、紫、橘等預設主題。
- 自訂主題：進階模式可調整 CSS 變數顏色，包括 `--bg`、`--accent`、`--accent-2`、`--soft`、`--border`。
- 範例色票：可快速套用夢幻紫、海洋藍、森林綠、夕陽橘。
- 本機自動儲存：表單內容會暫存在瀏覽器的 localStorage，重新整理後仍可保留。
- 放大預覽：右下角浮動按鈕可開啟全畫面式預覽。
- 重設確認：按下重設範例前會先確認，避免誤刪學生內容。

## 教學用途

這份工具適合用在：

- 國中資訊課程
- HTML/CSS 入門活動
- 個人學習歷程或畢業網站製作
- 讓學生理解網頁內容、樣式和原始碼之間的關係

老師可以先讓學生用表單完成自己的頁面，再切換到「看 HTML」觀察：

- `<title>` 如何對應瀏覽器分頁標題
- `<h1>`、`<p>`、`<section>` 如何組成網頁內容
- CSS 變數如何控制整體顏色
- 圖片 URL 如何放進 `<img>`


## 注意事項

- 圖片請使用可公開訪問的圖片 URL。
- 如果圖片連結無法載入，預覽中可能不會顯示該圖片。
- 下載出的 `example.html` 是完整獨立網頁，可以再交作業、上傳或另外修改。
- localStorage 只會存在同一台電腦與同一個瀏覽器中，不會同步到其他裝置。

## 技術資訊

- 純 HTML、CSS、JavaScript
- 無外部套件
- 無 build step
- 可離線開啟使用，但圖片 URL 仍需要網路才能載入
